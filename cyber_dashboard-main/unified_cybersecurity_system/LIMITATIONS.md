# Limitations

- The included ML architectures have no registered trained checkpoint or reproducible evaluation artifact. The running platform therefore uses a transparent heuristic fallback, not a trained attack-state prediction model.
- `DEMO` telemetry is reproducible synthetic input. There is no implemented enterprise streaming connector, SIEM, EDR, SOAR or response action.
- Propagation is topology risk diffusion, not a validated GNN forecast. Time-to-critical-asset and counterfactual defence remain unimplemented because no defensible calibrated model/evidence is available.
- State and audit evidence are in-memory for local demonstration. Restarting the app clears them.
